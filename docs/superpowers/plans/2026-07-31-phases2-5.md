# Phases 2-5: Capture, Organization, Collaboration, UX — Implementation Plan

## Task 1: Self-destructing notes
- Add `selfDestructAt` and `selfDestructOnRead` to Note model (already in schema)
- On app open/resume: check for notes where `selfDestructAt <= now`, delete them
- On opening note editor: if `selfDestructOnRead`, delete immediately
- Visual indicator (timer icon) on note cards

## Task 2: OCR from photo
- Add `google_mlkit_text_recognition`, `image_picker` deps
- OCR service: pick image, run ML Kit, return text
- Button in editor toolbar → bottom sheet
- Insert text at cursor position

## Task 3: Voice-to-note transcription
- Add `record`, `speech_to_text`, `permission_handler` deps  
- Recording service: record audio, transcribe, return text + audio path
- Microphone button in editor → recording UI with waveform
- Audio file retained as attachment (stored locally, Firebase Storage if synced)

## Task 4: Location-tagged notes
- Add `geolocator`, `geocoding`, `flutter_map` deps
- Location service: one-time capture, reverse geocode, return coords + place name
- "Add location" button in editor → map preview
- Lat/lng in Note model (already in schema)

## Task 5: Wiki-style [[links]] with backlinks
- Detect `[[` in content → autocomplete dropdown of note titles
- On save: parse `[[...]]`, resolve to note IDs, store in `links` array
- Render as tappable inline links in preview
- Backlinks section at bottom of note
- Broken links shown with strikethrough

## Task 6: Spaced repetition / flashcards
- SM-2 algorithm implementation
- Flag note as study material
- Review view: show question → tap to reveal → rate 1-4
- Due count badge in app bar
- Daily notifications via `flutter_local_notifications`

## Task 7: Version history with restore
- Subcollection `versions/{versionId}` per note
- Save snapshot on each save (rate-limited: 1 per 5 min, max 50)
- List view with timestamps, previews, Restore button
- Delete note = delete all versions

## Task 8: Real-time shared notes
- Add `collaborators` array + `encryptedKeys` map to Note model
- Share button → invite by email
- Collaborator access enforced by Firestore rules (already defined)
- E2EE key sharing: Note Key encrypted with collaborator's public key
- Owner can remove collaborators

## Task 9: Comment threads
- Subcollection `comments/{commentId}`
- Flat list at bottom of shared notes
- Real-time via Firestore snapshots
- Comments always plaintext

## Task 10: Context switcher / focus view
- Tags (array on Note model)
- Tag management UI (create/edit/delete/assign)
- Context switcher sidebar/bottom sheet
- Filter notes by tag
- Focus mode
